# Proyecto Final
Hola mi nombre es Kevin Leonardo Guzmán Gurrola y este es mi proyecto, que formara parte de mi calificación en las materias de "Introducción a la programación en software" y "Laboratorio a la programación en software"

¿Qué hace el programa?

Mi programa consiste en una calculadora básica desarrollada en Python utilizando la biblioteca Tkinter. Su función principal es permitir al usuario realizar operaciones aritméticas básicas como suma, resta, multiplicación y división mediante una interfaz gráfica. El usuario puede ingresar números y operadores utilizando botones, visualizar la operación en pantalla y obtener el resultado al presionar el botón "=". Además, cuenta con un botón "C" para limpiar el contenido de la pantalla.

¿Qué partes del código implementaste tú?

Durante el desarrollo del proyecto implementé las siguientes partes:

La creación de la ventana principal de la calculadora utilizando Tkinter.
El diseño de la interfaz gráfica mediante el uso de botones y un campo de entrada.
La función agregar_numero(), que permite mostrar en pantalla los números y operadores seleccionados.
La función realizar_operaciones(), encargada de evaluar la expresión matemática y mostrar el resultado.
La función limpiar(), que elimina el contenido del campo de entrada.
La organización de los botones mediante una cuadrícula (Grid) para que la calculadora tuviera una apariencia ordenada y similar a una calculadora real.
La configuración de los eventos para que cada botón ejecutara la acción correspondiente al ser presionado.

¿Qué aprendiste durante el desarrollo?

Durante el desarrollo de este proyecto aprendí varios conceptos importantes de programación, entre ellos:

El uso de la biblioteca Tkinter para crear interfaces gráficas en Python.
